# 임성혁 풀이 폴더

## 📝 사용법
1. `template/Main.java` 파일에 문제 풀이 코드를 작성합니다
2. 커밋 메시지에 문제 정보를 포함하여 커밋합니다
   - 형식: `[플랫폼] 문제번호 문제명`
   - 예: `[BOJ] 1234 요세푸스문제`
3. `ish` 브랜치에 push하면 GitHub Actions가 자동으로 처리합니다

## 🤖 자동 처리 내용
- ✅ 커밋 메시지에서 문제 정보 추출
- ✅ Main.java를 `.md` 형식으로 변환
- ✅ `월/주차/` 폴더에 저장 (예: `02/week1/BOJ_1234_요세푸스문제.md`)
- ✅ `weeklyCode/월/주차/`에 이름 포함하여 저장
- ✅ Main.java 초기화 (다음 문제를 위해)

## 📂 폴더 구조
```
임성혁/
├── template/
│   └── Main.java          # 여기에 풀이 작성!
├── 02/
│   └── week1/
│       ├── BOJ_1234_요세푸스문제.md
│       └── BOJ_5678_단지번호붙이기.md
└── 03/
    └── week1/
```

## 💡 TIP
- IntelliJ에서 `임성혁` 모듈을 선택하면 Main.java 실행 가능
- JDK 11 사용
- 문제명은 생략 가능 (예: `[BOJ] 1234`)
